# Challenges and Learnings

## Challenges

## 1. Learning PyTorch and Deep Learning Workflow

At the beginning of the project, understanding how all the parts of a deep learning project connect together was challenging. I learned how different components work together:
Image Data → Preprocessing → Dataset → CNN Model → Training → Inference
Building each part step by step helped me understand the complete workflow instead of only focusing on the final result.

## 2. Model Training and Computer Limitations

One of the challenges I faced was training the CNN model on my computer. Since my system uses a CPU instead of a faster GPU, the training process took a long time.
To manage this, I learned to monitor the training process carefully and approach the training in smaller steps. I trained the model gradually and tested different parts of the pipeline instead of trying to complete everything at once.
This helped me understand how training time, hardware, and model complexity affect deep learning projects.


## 3. Debugging Errors and Problem Solving

During development, I faced different errors related to file paths, Python packages, dataset organization, and model implementation.

Solving these problems taught me how to read error messages, search for solutions, and debug my code patiently.



#Learning

The most important part of this project for me was learning new tools that are used in real-world development.

I learned how to use:

- Git and GitHub for version control.
- MkDocs to create professional project documentation.
- Streamlit to build an interactive machine learning application.
- PyTorch and OpenCV for deep learning and image processing.

Using these tools helped me understand how machine learning projects are developed, organized, and presented professionally. It was a very wonderful experience.
