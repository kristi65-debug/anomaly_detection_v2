#Steel Surface Defect Classification
##Project Overview

This project uses deep learning and computer vision to classify steel surface images into different categories. The goal is to automatically detect whether a steel image has a defect and identify the type of defect.

A Convolutional Neural Network (CNN) is trained using labeled steel images. The model learns patterns from the images and can later predict the defect class of new unseen images.

## Project Workflow

The project follows these main steps:

1. **Preprocessing** - Resize and prepare images before training.
2. **Dataset Preparation** - Organize images and assign labels.
3. **CNN Model** - Build a deep learning model to recognize image    patterns.
4. **Training** - Teach the model using training images and evaluate performance.
5. **Inference** - Use the trained model to make predictions on new images.
